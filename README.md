# AnanMoney

AnanMoney 是一個單頁式個人記帳工具，主要介面集中在 `index.html`。資料預設儲存在瀏覽器本機，也可以透過 Google Apps Script Web App 同步到 Google 試算表。

## 功能模組

### 首頁總覽

- 顯示目前淨資產、現金資產、股票資產與信用卡負債。
- 顯示最近記帳、未結清分帳、儲蓄目標與信用卡提醒。
- 提供快速進入記帳、資產、分析、設定等常用入口。

### 每日收支行事曆

- 以月曆方式查看每日收入、支出、轉帳與信用卡繳款。
- 支援自訂行程與 2026 台灣國定假日/補假標記。
- 每個日期格會預留紀錄空間，節日與事件過長時以省略顯示。
- 信用卡繳款截止日會依設定自動顯示在行事曆。
- 點選日期後可查看該日完整收支、節日與信用卡繳款資訊。

### 新增記帳

- 支援支出、收入與帳戶轉帳。
- 分類與子分類可從選單選擇，選擇「其他」時可自行輸入。
- 支出與收入可綁定帳戶、專案與備註。
- 轉帳可設定來源帳戶、目的帳戶、日期與備註。
- 支出、收入與轉帳都可設定為固定項目，之後可一鍵快速記帳。

### 分攤記帳

- 支出可輸入分攤參與者，一行一位或用逗號分隔。
- 可手動輸入自己的負擔金額；留空時會以「自己 + 參與者」平均分攤。
- 自己先付時，會為每位參與者建立應收款。
- 對方先付時，會建立自己應付款。
- 分帳頁會彙整我該收、我該付與淨額，並可逐筆結清。

### 收支分析

- 顯示支出分類占比、收入趨勢與支出趨勢。
- 可快速觀察主要支出來源與近期金流變化。

### 資產總覽

- 彙整銀行活期、電子支付、股票、保險、現金、外幣現金、儲值卡與其他資產。
- 資產明細卡片會依視窗寬度自動調整欄數與卡片大小。
- 每個帳戶可個別隱藏或顯示金額。
- 外幣帳戶會依匯率換算約當台幣。

### 帳戶管理

- 可新增、編輯、排序與刪除帳戶。
- 支援資產、其他資產與負債分類。
- 可設定幣別、帳戶類型、基準餘額與備註。
- 帳戶清單會依視窗寬度調整顯示，避免文字擠壓。

### 帳戶明細

- 顯示單一帳戶的目前餘額、收入、支出與轉帳紀錄。
- 可從帳戶明細快速追蹤該帳戶的所有交易。

### 信用卡帳單

- 可新增與管理信用卡、信用額度、本期應繳、結帳日與繳款截止日。
- 可綁定繳款帳戶，手動記錄繳款時會從指定帳戶扣款並沖減信用卡未繳金額。
- 可設定到期日自動繳款。
- 支援逾期後一鍵補記繳款。
- 本期清除繳款後，繳款截止日會自動累進到下一期。

### 專案記帳

- 可建立旅遊、活動或其他專案。
- 收支可歸到指定專案，方便後續統計。
- 適合追蹤旅行、活動、家庭共同支出等期間型帳務。

### 股票資產

- 可新增台股/ETF 股票代號、股數與成本。
- 本機 XAMPP 環境可透過 `stock-proxy.php` 查詢行情。
- 資產總覽會將股票市值納入淨資產。

### 儲蓄目標

- 可設定目標名稱、目標金額與目前已存金額。
- 首頁會顯示進度條，方便追蹤儲蓄進度。

### 收據與發票解析

- 支援電子發票 QR Code/文字解析雛形。
- 解析結果可協助帶入記帳備註。
- 若瀏覽器不支援掃描，可改用手動輸入。

### 設定中心

- 管理帳號、外觀、資料、功能與通知設定。
- 支援 PIN、顯示名稱、Google Email、資產金額顯示、提醒開關等設定。
- 可匯出/匯入 JSON 備份。
- 可依日期區間匯出 CSV。
- 可連線 Google 試算表進行測試、上傳與下載。

## 資料儲存與同步

- 本機資料儲存在瀏覽器 `localStorage`。
- JSON 匯出可完整備份目前資料。
- CSV 匯出主要提供記帳紀錄報表。
- Google 試算表同步由 `google-apps-script/Code.gs` 提供 Web App 端點。
- 同步資料會依使用者識別分流，避免不同使用者資料混在一起。

## 專案檔案

- `index.html`：主要應用程式，包含 UI、狀態、渲染、記帳邏輯與設定。
- `google-apps-script/Code.gs`：Google Apps Script 同步端點。
- `stock-proxy.php`：本機股票行情代理，主要供 XAMPP 開發測試使用。
- `README.md`：專案與模組說明。

## 使用方式

1. 直接開啟 `index.html`，或部署到 GitHub Pages。
2. 預設 PIN 為 `0000`。
3. 在「設定中心」調整帳號、外觀、資料同步與功能開關。
4. 若要使用 Google 試算表同步，先部署 `google-apps-script/Code.gs` 為 Web App，再於設定中心填入 Web App URL 與同步安全碼。

## 開發備註

- 應用主要以原生 HTML、CSS、JavaScript 實作。
- 前端不需要建置流程。
- 修改 `index.html` 後可直接重新整理瀏覽器檢查畫面。
- 若部署在 GitHub Pages，推送到對應分支後網站會依 GitHub Pages 設定自動更新。
