# AnanMoney

AnanMoney 是一個單頁式個人記帳工具。前端主要集中在 `index.html`，資料預設儲存在瀏覽器本機，並可選擇同步到 Google 試算表。

## 專案特色

- 不需要建置流程，開啟 `index.html` 即可使用。
- 支援支出、收入、轉帳、信用卡繳款與分攤記帳。
- 以日曆、資產、帳戶、專案、分析等不同視角整理個人財務。
- 支援固定支出、固定收入、固定轉帳的一鍵記帳。
- 支援 JSON 備份、CSV 匯出與 Google 試算表同步。
- 介面針對手機與桌面做響應式調整。

## 主要檔案

- `index.html`：主要應用程式，包含 HTML、CSS、JavaScript、資料狀態與互動邏輯。
- `google-apps-script/Code.gs`：Google 試算表同步使用的 Apps Script Web App。
- `stock-proxy.php`：本機 XAMPP 測試股票行情時使用的代理端點。
- `README.md`：專案說明文件。

## 使用方式

1. 直接開啟 `index.html`，或部署到 GitHub Pages。
2. 預設 PIN 為 `0000`。
3. 進入「設定中心」調整帳號、外觀、資料、功能與通知。
4. 若要同步 Google 試算表，先部署 `google-apps-script/Code.gs` 為 Web App，再於設定中心填入 Web App URL 與同步安全碼。

## 功能模組

### 1. 首頁總覽

首頁提供目前財務狀態摘要：

- 淨資產
- 現金資產
- 股票資產
- 信用卡負債
- 未結清分帳
- 儲蓄目標
- 最近收支
- 常用功能捷徑

### 2. 每日收支與行事曆

日曆區分為「每日收支」與「行事曆」兩個頁籤，避免收支資料與純行程混在一起。

- 每日收支頁籤會顯示收支摘要、行程精簡標籤、節日與信用卡繳款。
- 行事曆頁籤只顯示行程與節日，不顯示收入、支出或信用卡繳款。
- 日期格會預留紀錄空間，標籤過長時會自動省略。
- 今日會自動依實際日期標示。
- 點擊日期會切換到該日並捲動到當日明細。
- 內建 2026 台灣國定假日與補假標記。
- 可新增、編輯、刪除自訂行程。
- 信用卡繳款截止日會依信用卡設定自動顯示。

### 3. 新增記帳

記帳頁支援三種交易類型。

#### 支出

- 設定金額、分類、子分類、帳戶、日期、專案與備註。
- 來源帳戶預設為「台幣現金」，可在設定中心修改。
- 可選擇信用卡作為支付來源。
- 可設定為固定支出，日後一鍵套用。
- 可搭配分攤記帳。

#### 收入

- 設定金額、分類、子分類、入帳帳戶、日期、專案與備註。
- 入帳帳戶預設為「台幣現金」，可在設定中心修改。
- 可設定為固定收入，日後一鍵套用。

#### 轉帳

- 設定來源帳戶、目的帳戶、金額、日期與備註。
- 來源帳戶預設為「台幣現金」，目的帳戶會避開同一個帳戶。
- 可設定為固定轉帳，日後一鍵套用。

### 4. 固定收支

固定項目會依目前記帳類型顯示：

- 固定支出
- 固定收入
- 固定轉帳

固定項目以「下拉選單」選擇，避免項目太多時撐開表單。選定項目後會顯示名稱、帳戶或轉帳路徑、金額，並提供三個操作：

- `記帳`：直接以今天日期建立一筆新紀錄。
- `套用`：將固定項目帶入表單，可修改後再儲存。
- `刪除`：移除該固定項目。

### 5. 分攤記帳

分攤功能用來處理朋友、家人或旅遊共同支出。

- 可輸入多位參與者，一行一位或用逗號分隔。
- 每位參與者可指定金額，例如 `小花 300、小明 500`。
- 未指定金額的參與者會分配剩餘金額。
- 可手動輸入自己的負擔金額。
- 若未輸入自己的負擔金額，系統會用「自己 + 參與者」平均分攤。
- 自己先付時，會為每位參與者建立應收款。
- 對方先付時，會建立自己應付款。
- 分帳頁會彙整「我該收」、「我該付」與淨額。
- 分帳項目可逐筆結清。

### 6. 收支分析

分析頁提供收支趨勢與分類概覽。

- 支出分類統計
- 收入趨勢
- 支出趨勢
- 圖表化呈現主要金流變化

### 7. 資產總覽

資產頁彙整所有帳戶與資產類別。

- 銀行活期
- 電子支付
- 台幣股票
- 保險
- 台幣現金
- 外幣現金
- 儲值卡/會員卡
- 其他資產
- 負債

資產明細卡片會依視窗寬度自動調整欄數與卡片大小，避免帳戶名稱與金額被擠壓。

### 8. 帳戶管理

帳戶管理頁用來維護所有資產與負債帳戶。

- 新增帳戶
- 編輯帳戶
- 刪除帳戶
- 上移/下移排序
- 設定幣別
- 設定帳戶類型
- 設定基準餘額
- 設定備註
- 個別控制帳戶金額是否顯示

### 9. 帳戶明細

帳戶明細頁顯示單一帳戶的交易狀態。

- 目前餘額
- 收入合計
- 支出合計
- 相關記帳紀錄
- 相關轉帳紀錄

### 10. 信用卡帳單

信用卡模組負責追蹤信用卡未繳金額與繳款。

- 新增與編輯信用卡。
- 設定信用額度。
- 設定本期應繳。
- 設定本期繳款截止日。
- 設定下一次結帳日。
- 綁定扣款帳戶。
- 可手動記錄繳款。
- 可到期日自動記帳繳款。
- 可逾期後一鍵補記繳款。
- 繳款會從扣款帳戶支出，並沖減信用卡未繳金額。
- 本期繳款完成後，繳款截止日會自動累進到下一期。
- 信用卡繳款日會顯示在日曆上。

### 11. 專案記帳

專案可用來追蹤旅行、活動、家庭支出或其他期間型帳務。

- 新增專案
- 編輯專案
- 將收支歸到專案
- 在總覽與分析中查看專案相關金流

### 12. 股票資產

股票模組用來追蹤股票與 ETF 資產。

- 新增股票代號
- 設定股數
- 設定成本
- 本機 XAMPP 可透過 `stock-proxy.php` 查詢行情
- 股票市值會納入資產總覽

### 13. 投資總覽

投資頁彙整股票資產狀態，方便查看持股市值、成本與損益。

### 14. 儲蓄目標

儲蓄目標可用來追蹤特定用途的存錢進度。

- 目標名稱
- 目標金額
- 目前已存金額
- 首頁進度顯示

### 15. 收據與發票解析

收據掃描提供簡化的輸入輔助。

- 支援電子發票 QR Code/文字解析雛形。
- 可將解析內容帶入備註。
- 若瀏覽器不支援掃描，可手動輸入。

### 16. 設定中心

設定中心分為帳號、外觀、檔案、功能與通知。

#### 帳號

- PIN
- 使用者名稱
- Google Email
- 本機使用者切換

#### 外觀

- 顯示名稱
- 資產金額顯示/隱藏
- 介面偏好設定

#### 檔案

- 匯出 JSON
- 匯入 JSON
- 匯出 CSV
- CSV 可匯出記帳、帳戶、信用卡、分帳、股票、專案、行事曆與固定項目
- 記帳紀錄 CSV 可選擇全部資料或指定日期區間
- Google 試算表測試連線
- Google 試算表上傳
- Google 試算表下載
- 顯示最後同步時間

#### 資料重設

- 所有金額可一鍵歸零。
- 可清空所有帳戶與帳務資料，並保留一個「台幣現金」帳戶。
- 重設、匯入、同步下載等高風險操作前會自動下載 JSON 備份。

#### 功能

- 分帳功能
- 股票功能
- 專案功能
- 固定收支提醒
- 其他功能開關

#### 通知

- 信用卡繳款提醒
- 固定收支提醒
- 其他提醒設定

## 資料模型概覽

主要資料集中於瀏覽器本機狀態：

- `transactions`：收入、支出、轉帳、信用卡繳款紀錄。
- `accounts`：帳戶與資產項目。
- `cards`：信用卡資料。
- `projects`：專案資料。
- `splits`：分攤與未結清款項。
- `stocks`：股票與 ETF 資產。
- `goals`：儲蓄目標。
- `events`：行事曆事件。
- `recurring`：固定支出、固定收入、固定轉帳。
- `settings`：使用者設定與同步設定。

## 資料儲存與備份

### 本機儲存

資料預設儲存在瀏覽器 `localStorage`。同一台裝置、同一個瀏覽器、同一個網址會使用同一份資料。

### JSON 備份

JSON 匯出包含完整狀態，適合做完整備份與還原。

下列操作會自動先下載 JSON 備份：

- 匯入 JSON 前
- 上傳 Google 試算表前
- 從 Google 試算表下載覆蓋本機前
- 重設為示範資料前
- 將所有金額重設為 0 前
- 清空所有帳戶前

### CSV 匯出

CSV 匯出支援多種資料表：

- 記帳紀錄
- 帳戶
- 信用卡
- 分帳
- 股票
- 專案
- 行事曆
- 固定項目

其中記帳紀錄可選擇全部資料或指定日期區間；其他資料表會匯出完整資料。

### Google 試算表同步

Google 試算表同步透過 Apps Script Web App 執行。

- 前端設定 Web App URL 與同步安全碼。
- 上傳會把目前本機資料同步到試算表。
- 下載會把試算表資料回復到本機。
- 同步資料會依使用者識別分流。
- 測試連線、上傳與下載成功後會記錄最後同步時間。
- 上傳與下載前會自動建立本機 JSON 備份。

## Google Apps Script

`google-apps-script/Code.gs` 負責接收前端同步請求，並將資料拆分到多個工作表。

常見工作表包含：

- 記帳紀錄
- 帳戶
- 專案
- 信用卡
- 分帳
- 股票
- 基金
- 目標
- 行事曆
- 定期收支
- 餘額歷程
- 中繼資料
- 設定

## 本機股票代理

`stock-proxy.php` 主要供 XAMPP 本機環境使用。若股票代號太短，前端會自動補成常見台股格式，例如 `50` 會轉為 `0050`。

## 開發方式

本專案沒有前端打包流程。

1. 修改 `index.html`。
2. 重新整理瀏覽器。
3. 使用瀏覽器開發者工具檢查錯誤。
4. 若改到同步功能，同步更新 `google-apps-script/Code.gs`。

可用以下方式檢查主要 JavaScript 語法：

```bash
node -e "const fs=require('fs');const html=fs.readFileSync('index.html','utf8');const m=html.match(/<script>([\s\S]*)<\/script>\s*<\/body>/);new Function(m[1]);console.log('script syntax ok');"
```

## 部署

若使用 GitHub Pages，推送到對應分支後，網站會依 GitHub Pages 設定自動更新。

若在本機測試：

- HTML 可直接開啟。
- 股票代理需要 XAMPP/PHP。
- Google 試算表同步需要可連線的 Apps Script Web App。

## 注意事項

- 清除瀏覽器資料可能會刪除本機記帳資料，建議定期匯出 JSON。
- Google 試算表同步前，建議先匯出 JSON 備份。
- 國定假日資料目前內建 2026 年，跨年度需要更新 `TW_HOLIDAYS`。
- 股票行情依代理來源而定，若來源變動可能需要調整 `stock-proxy.php`。
